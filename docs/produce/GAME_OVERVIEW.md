# magic-slide — このゲームはどういうゲームか

プレイヤーの立場から見た、このゲームの説明と構成要素の整理。後半では、権利上の置換が必要な部分を洗い出す。

**置換後に何を使うかは、ここでは決めない。** それは戦略（IP・世界観の方針）が固まってから決める、このPJ本体の作業にあたる。ここで扱うのは「どこを置換しなければならないか」の特定まで。

ルールの細かい数値（グリッドの寸法、スコア計算式、難易度テーブルなど）は、アーカイブ済みの [GAME_DESIGN.md](../archive/2026-09-mitsumori-ip-poc/game/GAME_DESIGN.md) にある。

---

## 1. ひとことで言うと

**ブロックを横にスライドさせて横一列をそろえて消す、落ち物系のパズルゲーム。** 魔女と魔法の世界がテーマ。1プレイは数分で終わり、ハイスコアを狙って何度も遊ぶ。

## 2. 遊び方（プレイヤーから見たルール）

- 盤面は横8マス×縦11マスで、幅1〜4マスのブロックが並んでいる
- ブロックを指で左右にドラッグしてスライドさせる。ほかのブロックはすり抜けられない
- 横一列が隙間なく埋まると、その列が消えて得点になる
- 1回スライドするたびに、下から新しいブロックの列がせり上がってくる
- 消えた列の上にあったブロックは下に落ちる。落ちた先でまた列がそろうと連鎖（コンボ）になり、得点が大きく伸びる
- ブロックが一番上まで積み上がるとゲームオーバー
- スコアが上がるほど難しくなる。動かせない石ブロックが増え、列の隙間も多くなる

## 3. 付加要素

| 要素 | プレイヤーから見た内容 |
|---|---|
| 壺のゲージ | スライドするたびに少しずつたまり、満タンになるとダイヤが出る |
| ダイヤ | 取るとボーナス得点になる |
| 石ブロック | 動かせない邪魔ブロック。列ごと消すか、アイテムで壊す |
| アイテム（ファイア・スライス・サンダー） | ブロックをまとめて壊す救済手段 |
| コンティニュー | ゲームオーバー時に、下3列を消して1回だけ続行できる（エンジンに内蔵） |
| スキン・ショップ | コインでブロックの見た目を変えられる。ガチャのようなレア度の演出がある |
| コイン | ゲーム内の通貨 |
| ベストスコア | 自己記録を保存する |

## 4. 画面の流れ

```
読み込み中（魔女のシルエット）
  → 遊び方（初回のみ）
  → タイトル（魔女のイラスト＋START）
  → プレイ
  → ゲームオーバー → （コンティニュー？）→ リザルト
  → タイトルへ戻る
```

これらの画面はすべてエンジン（`bundle.js`）がcanvas上に描画している。シェル側（Next.js）は、iframeでゲームを載せて通信を中継しているだけになっている。

## 5. このゲームの魅力の核（仮説）

- **ルールが一瞬で分かる**：「横にずらしてそろえる」だけ
- **1手ごとに状況が悪化していく緊張感**：スライドするたびに下から列が迫ってくる
- **連鎖の気持ちよさ**：落下で連鎖がつながり、得点が段違いに伸びる
- **壺・ダイヤ・アイテムという救済と報酬のリズム**

この核は**ルールと演出の組み合わせ**でできている。置換で見た目を変えても、ルールと手触りが残れば核は保たれる、というのが前提になる。

「元のゲームを知っている人が見て、元のゲームだと分かるもの」を基準に洗い出した。

### B. プログラム（プレイヤーには見えないが、権利の本体）

| 中身 | 場所 | 扱い |
|---|---|---|
| ゲームエンジン本体 | `bundle.js` | **vendorのプログラムそのもの。** アセットを全部差し替えても、これが残る限り複製物のまま。最終的には自前のエンジンへの置き換えが必要 |
| vendorのSDK・ラッパー | `lib/SCG-gmo-pixim.min.js`、`public/game/gamebox.iframe.js` | 同上 |
| OSSライブラリ | `lib/pixi-legacy`、`howler`、`createjs`、`Pixim*` | ライセンスを確認したうえで使い続けられる見込み（PixiJS・howler.js・CreateJSはMITライセンス） |

エンジンにはゲームのロジックとコンテンツ（演出のタイミング、アセットの参照、UIの配置）が一体になって入っている。そのため**アセットの置換とエンジンの内製化は、きれいには分けられない**。これが置換作業の難しさの本体になる。

### C. シェル側（Next.js）

| 中身 | 場所 | 扱い |
|---|---|---|
| ページのタイトル・説明文 | `src/app/layout.tsx`（「マジックスライド」、元サイトの紹介文） | **必須** |
| favicon・ホーム画面アイコン | `public/seo/*`（元ポータル由来） | **必須** |
| リザルト背景など | `public/images/bg-win.png`、`icon-heart-off.png` | **必須**（現在のUIで使っているかも含めて確認） |
| 元サイトのCSS | `src/app/shell.css`（元サイトのCSSをそのまま移植） | 優先度は低い。ただし見た目の意匠として整理が必要 |

### D. 使っていないのに公開されてしまうもの（すぐ対処すべき）

`public/images/` には、**元ポータルに載っていた他のゲーム24本分のサムネイル**（`141.png`〜`795.png`）、元サイトの`app.css`・`timesale.css`、jQueryなどが、どこからも参照されないまま残っている。これらはデプロイすると静的ファイルとして公開状態になる。今回のゲームとは無関係な他社のアセットなので、**置換の議論を待たずに削除してよい**。
