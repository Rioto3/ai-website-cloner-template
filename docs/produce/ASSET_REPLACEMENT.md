# magic-slide — 置換が必要な素材の整理と、仮置きの方針

[GAME_OVERVIEW.md](GAME_OVERVIEW.md)の「置換対象」を、実際のファイルから数え直し、**役割ごと**に整理した。目的は、権利上の問題を直ちに解決しつつ、UXを大きく変えずに、仮置きの素材へ置き換えること。仮置きの素材は、独自性を少し入れた、今後の議論の叩き台にもなる。

数え方の根拠：`public/game/magicslide/assets/`の画像シート（`*.json`のフレーム名）、演出（`animate/`）、音（`sound/`）、言語ごとの画像、`config.json`。ファイル名からの推測を含む部分は「推測」と書いた。

## 先に押さえておくこと

**仮置きの素材を使う先は、自前のエンジンにする。** 元のエンジン（`bundle.js`）に、素材だけを差し替えて使う方法は、おすすめしない。理由は3つ。

1. `bundle.js`は、画像のフレーム名73個と、10種類のパスをコードに直書きしている
2. 演出（`animate/`の20ディレクトリ）は、Adobe Animateの書き出しで、絵と動きが一体になっている。絵を替えると、動きも作り直しになる
3. 替えても、`bundle.js`自体（vendorのプログラム）は残るので、権利の問題は解決しない

つまり、素材の置換は、Web版のコア作り（[L0_PLAN.md](L0_PLAN.md)の50〜80時間）と**同時に**行う作業になる。それまでは、元のランタイム（`public/game/`）を、Cloudflare Accessで保護したまま残す。

## 素材の全体像（数字）

| 種類 | 量 |
|---|---|
| 画像シート（`commons/sheet/`） | 2.8MB。ブロックのスキン5種、UI、数字、文字のフォント、読み込み画面など |
| 演出（`commons/animate/`） | 4.2MB。20ディレクトリ |
| 単体の画像（`commons/image/`） | 14枚。背景、盤面の線、ポップアップ、マスクなど |
| 言語ごとの画像（`languages/`） | 456KB。日本語と英語の、ロゴ、遊び方、文字画像 |
| 音（`commons/sound/`） | 924KB。BGM 1曲と、効果音23種 |
| バランス表（`config.json`） | 4.2KB。難易度、スキンの排出率 |

**L0のスコープ（コア、続行、テーマ素材、音。ブースター、ショップ、ガチャ、コイン、壺とダイヤは作らない）では、演出の約55%、音の約45%が不要になる。** 置換が必要なのは、コアの体験に関わる役割だけ。

## UXを守るための決まり

「よっぽどUXが変わるもの」を避けるため、仮置きの素材は、次を守る。

1. **盤面の大きさと、画面の比率を変えない。** 8列 × 11行、1マス80px、論理サイズは720×1280
2. **ブロックの幅は、マス数 × 80pxにする。** 幅1〜4が、見分けられる
3. **色は、色だけに頼らずに判別できるようにする。** 記号などを併用する
4. **石は、動かせないと一目で分かるようにする。**
5. **ドラッグのガイドと、危険の警告は、同じ位置・同じ長さ・同程度の強さにする**
6. **消去と連鎖の演出の長さを、元と同程度にする。** 演出が終わるまでの待ち時間や、次に操作できるまでの間が変わると、テンポが変わる。元の長さは、`animate/`のフレーム数から**実測して合わせる**（未実施）
7. **操作の応答ごとに、必ず対応する音を置く。** 置く、消える、連鎖、ベスト更新、ボタン
8. **文字は、画像ではなく文字として出す。** 日本語だけなので、Webフォントで足りる

## 仮置きの素材の作り方

- **コードで生成する。** 画像はSVG、音は合成した音声ファイルを、生成するスクリプトで作る。生成物は、こちらで作ったものなので、権利の問題がなく、後から調整もしやすい。追加の費用もかからない
- **形式は、ReactNativeでも使えるものにする。** 画像はSVGかPNG、音は音声ファイル。ゲームのロジックから、素材を直接読み込まない
- **置き場所：** `public/theme/placeholder/`（案）。生成するスクリプトは`scripts/`に置く
- **仮の名前をつける。** 商標の問題を避けるため、仮題は「（仮）」をつけた、一般的な言葉にする

### 仮のテーマ（叩き台）

独自性を少し入れる。決まったものではなく、議論の叩き台。

- **案：和菓子。** ブロックを、練り切りのような丸みのある和菓子に見立てる。色は、桜（ピンク）、抹茶（緑）、柚子（黄）、藍（青）の4色。石ブロックは、灰色の石のまま。日本の35歳以上の女性向けという方向にも合う
- 他の候補：園芸、純喫茶、動物（[SUCCESS_DEFINITION.md](SUCCESS_DEFINITION.md)のテーマの方針を参照）
- 素材を一貫して作れることが条件。テーマは、後から差し替えられるようにしておく

## 次にやること（案）

1. 仮のテーマを決める（上の案でよいか）
2. 役割A〜Kのうち、コアの体験に必要な素材を、生成するスクリプトで作る
3. 元の演出の長さを、`animate/`から実測する
4. 自前のエンジン（Web版のコア）に、仮置きの素材を組み込む
5. 置き換えが済んだら、`public/game/`を削除する
