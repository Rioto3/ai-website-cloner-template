# ミツモリ村 — アートディレクション

## 1. アートコンセプト

> **「絵本のページの中で、ゼリーがぷるんと動く」**

- 参照系統: 絵本的フラット（スージー・ズー系のあたたかさ）× 現代パステル（すみっコぐらし的余白）
- 3原則:
  1. **まるい**: 直角を作らない。最小角丸 8px（80pxセル基準で r=18 目安）
  2. **あまい**: 全色にクリームを1滴混ぜる（純色禁止 — 下のパレットで統一）
  3. **ぷるん**: 動くものはすべて squash & stretch。硬い等速移動禁止

## 2. カラーパレット

### ベース（世界の色）
| 用途 | HEX |
|---|---|
| 蜜アンバー（ブランド主色） | `#F5A83C` |
| クリーム（地・紙） | `#FFF6E3` |
| 幹ブラウン（枠・文字） | `#8C6239` |
| 葉っぱグリーン（環境） | `#9BD77E` |
| そらブルー（背景上部） | `#BFE7F2` |
| 夕暮れアプリコット（**危険表現**） | `#F2955F` |

### ゼリー4味（ブロック色 = エンジンの color 0–3）
| color | 味 | 本体 | ハイライト | 判別アイコン（色覚対応） |
|---|---|---|---|---|
| 0 | いちご | `#FF8FA3` | `#FFC2CE` | ♥ ハート |
| 1 | レモン | `#FFD35C` | `#FFE9A8` | ★ ほし |
| 2 | メロン | `#8ADB8A` | `#C3F0C3` | 🍃 はっぱ |
| 3 | ソーダ | `#7CC8F5` | `#BDE6FF` | 💧 しずく |

- **色覚対応は必須仕様**: 色だけに頼らず、各味に固有の刻印アイコン+明度差を持たせる。
- カラどん（石）: `#B8A88F` 本体 / `#8C7B62` 帽子。彩度を落とし「動かせない」ことを直感させる。
- 金のしずく: `#FFC93C`→`#FFAA00` グラデ + 白ハイライト。画面上で最も明るい存在に予約。

### 危険表現（重要）
赤の点滅は世界観違反。積み上がり警告は**空が夕暮れ色に変わる**（背景を
`#BFE7F2`→`#F2955F` へクロスフェード）+ ミモの表情が「あせり顔」になる。

## 3. 形状言語

- **ゼリーブロック**: 上面ハイライト付きの角丸矩形（r=18/80px）。縁は幹ブラウンの
  2.5px アウトライン。幅2〜4のブロックは同一面に刻印を weight 個ではなく**1個**（中央）。
- **キャラクター**: 2.5頭身、点目+チーク基本。輪郭はクリーム色の太フチ（ステッカー風）
  → 背景から浮き、グッズ転用が容易。
- **背景**: 3層パララックス相当（空グラデ / 遠景の丘と木 / 手前の蜜棚枠）。
  棚枠は木目のフレームで、旧作の「黒レターボックス」を**木の幹の内壁**に置き換える。

## 4. モーション原則

| イベント | 演出 | 時間 |
|---|---|---|
| ドラッグ開始 | ブロックが 1.06倍に「ぷく」と膨らむ | 90ms |
| スナップ着地 | squash（y 0.92）→戻り | 160ms |
| ライン出荷 | 白フラッシュ→ゼリーが縮んで跳ね、蜜の粒が散る | 350ms |
| 行せり上がり | 下から ease-out で 1セルぶん上昇 | 240ms |
| 壺満タン | 壺が揺れて金のしずくが跳ね出る | 800ms |
| コンボ | ラテ&ミルクの吹き出し「あまい連鎖！」がぽよんと出る | 600ms |
| ゲームオーバー | 空が夕暮れ→ミモがぺこり「きょうはここまで」 | 1200ms |

- イージングは `cubic-bezier(0.34, 1.56, 0.64, 1)`（backOut）を標準とする。
- 60fps を守れない演出は入れない（パーティクルは最大12粒）。

## 5. 素材制作ガイド

- 一次素材はすべて**SVG**（`src/components/mitsumori/art.tsx` に実装済みのものが正）。
  拡大に強く、テーマカラーの一括変更が可能。
- ラスタ書き出しは 2x 基準（旧作と同じ resolution:2 方針）。
- 既存のミラー済みアトラス（`public/game/magicslide/assets/`）は**構図・サイズの参考**として
  のみ使用し、新IPには流用しない（権利分離のため）。
