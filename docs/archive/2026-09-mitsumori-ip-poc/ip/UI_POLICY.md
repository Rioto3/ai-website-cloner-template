# ミツモリ村 — UI方針

## 1. 原則（5つ）

1. **親指ファースト**: 主要操作（スライド/一時停止/ブースター）は下半分に集約。
   旧作のレイアウト（下部にブースター/壺/ポーズ）は正しいので踏襲する。
2. **文字より絵**: ボタンは「アイコン+最大6文字」。チュートリアルはビィの一言吹き出しで進める。
3. **状態はキャラが語る**: スコア枠のミモ表情（通常/にこにこ/あせり）、コンボはラテ&ミルク、
   記録更新はモク長老。数値の点滅で語らない。
4. **失敗を叱らないUI**: GAME OVER の代わりに「きょうはここまで」。リトライは
   「もういちど」（continue相当は「おてつだいを呼ぶ」= 広告/アイテム枠）。
5. **色覚・片手・低速端末対応**: 判別アイコン刻印（ART_DIRECTION §2）、60fps優先、
   タップターゲット最小 44px。

## 2. 画面別ポリシー

### タイトル
- ロゴ（蜜が垂れるモチーフ）+ ミモ&ビィ立ち絵 + START。
- ボタンは蜜アンバーの丸ピル+幹ブラウン文字。押下で「ぷに」と縮む。
- 下部に 型屋さん（ショップ）/ ことば（言語）を小さく。旧作のカート/地球アイコン踏襲。

### プレイ（HUD）
| 位置 | 要素 | ミツモリ版 |
|---|---|---|
| 左上 | プレイヤー枠 | ミモの顔（状態で表情差分） |
| 中上 | TARGET | 「きょうの出荷ノルマ」木の看板 |
| 右上 | BEST | モク長老の記録帳 |
| 上帯 | レベルゲージ | 蜜色のプログレスバー（ピンク→蜜アンバー） |
| 右上2 | コイン | ハニーコイン |
| 下中央 | 壺ゲージ | 大きなはちみつ壺（蜜がたまる/金のしずくが跳ねる） |
| 下左 | ブースター | ポカポカの実（残数バッジ） |
| 下右 | ポーズ | 葉っぱの一時停止ボタン |

### 一時停止 / 設定
- 木の看板モーダル。「つづける / おと / ことば / やめる」の4項目まで。

### リザルト
- 「きょうの出荷: {score}」→ 金のしずく換算のご褒美演出 → ノルマ達成でチケット（既存の
  今日の目標システムに接続）。

## 3. コンポーネント規約

- 角丸: ボタン=ピル、カード=24px、ブロック=18px。
- 影: `0 4px 0 rgba(140,98,57,.25)`（ベタ落ち影。ぼかし影は使わない=絵本感）。
- フォント: 丸ゴシック系（M PLUS Rounded 1c / システムは Hiragino Maru Gothic フォールバック）。
  数字は太字、和文は500。
- モーダル出現: 200ms backOut スケール（0.9→1）。黒オーバーレイは `rgba(92,64,36,.45)`
  （茶色がかった暗さ=木の中の暗さ）。

## 4. 実装マッピング（本リポジトリ）

- テーマ定数: `src/game/theme/mitsumori.ts`
- SVG素材: `src/components/mitsumori/art.tsx`
- プレイアブル: `/play` ルート（`src/app/play/page.tsx` → `MitsumoriGame`）
- 既存クローンシェル（`/`）はリファレンスとして保持。新IPのシェルはPhase 2で置換。
