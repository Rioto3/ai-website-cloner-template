## 1. IPコンセプト

### 一言で
> **大きなハチミツの木のふもとで、こぐまのミモが「蜜ゼリー」を並べて出荷する、
> あまくてちょっとあわてんぼうな村のおはなし。**

### コアアイデンティティ
| 要素 | 定義 |
|---|---|
| IP名 | **ミツモリ村**（Mitsumori Village）— 「蜜」+「森」。商標として独自性があり、拡張可能 |
| ゲームタイトル | **ミツモリスライド** |
| タグライン | 「スライドして、あまーい一列。」 |
| ジャンル感情 | **コージー×ちょいハラハラ**。癒し系の見た目で、棚があふれそうになる緊張感 |
| 対象 | 20–40代・カジュアルパズル層（既存ゲーム広場ユーザーと同一）+ キャラグッズ層への拡張余地 |
| トーン | やわらかい、まるい、あまい。敵・悪役は存在しない。「困りごと」だけがある |

## 2. 世界観

### 舞台
森のまんなかに立つ巨大な**ハチミツの木**。幹の中は空洞で、はちみつが「蜜ゼリー」として
棚に実る。ふもとの**ミツモリ村**の動物たちは、このゼリーを収穫・出荷して暮らしている。
季節ごとに木の蜜の味が変わる（＝シーズンイベントの器）。

### 世界のルール（3つだけ。増やさない）
1. **木は毎日ゼリーを実らせる。** 村はそれを一列そろえて出荷する（デイリープレイの動機）。
2. **壺に蜜がたまると「金のしずく」が生まれる。** 村いちばんのごちそう（ジャックポットの快感）。
3. **カラどんは悪者ではない。** 眠いだけ。出荷の列に巻き込まれると照れて転がっていく（石ブロック消去の演出）。

### 物語フック（運営で少しずつ開示）
- ハチミツの木は「はじまりのミツバチ」が植えたと言われている — ビィの秘密。
- 金のしずくを集めると、木のてっぺんの「星の巣箱」に何かが起きる…（コレクション動機）。

## 3. キャラクター

### メインキャスト
| キャラ | 種 | 役割（UI/ゲーム内接点） | 性格・設定 |
|---|---|---|---|
| **ミモ** | こぐま（主人公） | プレイヤーの分身。ヘッダーで表情が変わる（旧: 魔女の顔枠） | はちみつ屋見習い。がんばりやで少しあわてんぼう。耳のリボンが蜜色 |
| **ビィ** | ミツバチ | ガイド役。チュートリアル・遊び方の説明担当 | 先輩風をふかす手のひらサイズの蜂。「ぶんっ」と飛んでツッコむ |
| **ラテ & ミルク** | うさぎの双子 | コンボ時に応援ポップ（旧: コンボ演出） | 村のカフェ担当。ラテは元気、ミルクはおっとり |
| **キナコ** | きつね | ショップ/型屋さんの店主（旧: スキンショップ） | パン職人。焼き型コレクター。「いい型入ったよ」 |
| **モク長老** | ふくろう | ベストスコア・記録の番人（旧: BEST表示） | ものしり。夜に記録帳をつけている |
| **トゲマル** | はりねずみ | ブースター説明役 | カラどんの殻割り名人。背中の針でポカポカの実を運ぶ |
| **カラどん** | どんぐりの殻 | 石ブロックそのもの | 眠いだけの困りもの。転がって退場する姿がかわいい、が正義 |

### キャラクター設計原則
- **全員が「仕事」を持つ**：ゲームのUI機能に1:1で対応させる（機能追加=キャラ追加の余地）。
- **セリフは10文字前後**：「出荷でーす！」「あまい連鎖！」「棚があふれる〜！」。ボイスなしでも成立する擬音的な言葉選び。
- **シルエット判別**：全キャラ、黒塗りシルエットで見分けがつく形状差（耳・羽・針・尾）。

## 4. ブランド

### ネーミング体系
- IP傘: **ミツモリ村** / ゲーム: **ミツモリスライド**（続編: ミツモリ○○で無限に拡張可）
- ロゴ: 丸ゴシック系の太文字＋蜜のしずくが「ス」から垂れるモチーフ。英字表記 *MITSUMORI SLIDE*

### ブランドカラー（詳細は ART_DIRECTION.md）
蜜アンバー `#F5A83C` / クリーム `#FFF6E3` / 木の幹ブラウン `#8C6239` を三本柱に、
ゼリー4色（いちご/レモン/メロン/ソーダ）をアクセントとする。

### ブランドボイス
- ひらがな多め、句点少なめ、「〜でーす」「〜だよ」。
- 数字の誇張をしない（「大量獲得!!」ではなく「きょうもあまい一日」）。
- 失敗を責めない語彙（ゲームオーバー→「きょうはここまで。よくがんばりました」）。

### 禁止事項
- 敵・戦闘・爆発の語彙とビジュアル（「はじける」はOK、「爆発」はNG）
- 彩度の高い赤の警告（危険表現は「夕暮れ色」で行う。ART_DIRECTION参照）
- キャラの等身上げ・リアル化
