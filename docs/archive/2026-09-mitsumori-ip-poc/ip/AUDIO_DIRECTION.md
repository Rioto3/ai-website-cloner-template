# ミツモリ村 — オーディオディレクション

## 1. 方向性

> **「昼下がりの村のラジオ」** — ウクレレとマリンバの、ゆるくて手作りな音。

- BPM 96 / メジャーキー（C）/ 8小節ループ（A4+B4）
- 編成: マリンバ（主旋律）、ウクレレ/ピチカート（伴奏）、グロッケン（キラ音）、
  ソフトベース、ブラシパーカッション
- ラウドネス: BGM -18 LUFS 目安、SFXはBGMより+3dBの帯域を空ける（中高域）
- **危険時（棚あふれ間近）**: 曲は変えず、ローパスを開いてテンポ感を出す/パーカッション追加
  （曲切替はコージー感を壊すため禁止）

## 3. 実装（本リポジトリでの一次実装）

外部音源なしで世界観を確認できるよう、**WebAudioによる手続き生成**で一次実装する:
`src/game/audio.ts`
- `MitsumoriAudio.startBgm()` — C調ペンタトニックのマリンバ風ループ
  （I–vi–IV–V 進行、矩形波を減衰エンベロープで丸めた疑似マリンバ+サイン波ベース）
- `pop() / knock() / chime() / drip() / fanfare()` — 上表の主要SFX
- すべてユーザー操作（STARTタップ）後に AudioContext を resume（自動再生制限対応）
- 音量: BGM 0.15 / SFX 0.3、ミュートトグルあり

## 4. 本制作への引き継ぎ（設計図）

- 発注時のリファレンス曲調: 「ぼのぼの」OP系の脱力感 + 任天堂『ヨッシー』系の
  マリンバ使い。歌なし。90秒ループ+イントロ4秒。
- 納品形式: 48kHz/24bit WAV原盤 + ゲーム用 128kbps mp3（旧作と同じHowler再生前提）。
- SFXは1音=1ファイル、上表の名前で `assets/commons/sound/` の命名互換にすると
  既存ミラーとの差し替え検証が容易。
